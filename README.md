### 🛠️ Local Development & Running the Application

```bash
# Clone repository
git clone https://github.com/AsadMERN/asadMERN.git

# Navigate into project
cd asadMERN

# Install dependencies
npm install

# Run local development server
npm run dev

# Open in browser: http://localhost:3000 (or http://localhost:3005)
```

To create an optimized production build:
```bash
npm run build
npm start
```
