# Muhammad Asadullah — Portfolio

A responsive Europass-inspired academic portfolio for Muhammad Asadullah, a Software Engineering graduate from Faisalabad, Pakistan.

## Included sections

- Personal profile
- Education and academic results
- Contact details and WhatsApp link
- Privacy-conscious handling of national identity information

## Technology

Next.js 14, React, TypeScript, Tailwind CSS, Framer Motion, and Lucide icons.

## Local development

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.
